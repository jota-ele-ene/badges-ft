Cómo verificar una insignia

Tu aplicación ya dispone de rutas para verificar por ID, por PNG y para comprobar el email del receptor, así que esta página presenta ese flujo de forma más clara para el usuario.

1

Sube un PNG o usa un identificador

Puedes verificar una credencial subiendo el badge en formato PNG con metadatos embebidos o consultando directamente una assertion ya generada.

2

Comprueba el resultado

La verificación debe resolver correctamente la assertion, el emisor, la imagen y, si corresponde, el hash del receptor para confirmar que la insignia es válida.

3

Revisa incidencias si falla

Si la URL del badge no es pública o responde con HTML en vez de imagen, la validación externa puede fallar aunque el fichero exista dentro del entorno de desarrollo.

Cómo interpretar el resultado

La plataforma puede ofrecer un estado válido o un estado que requiere revisión en función de si todos los recursos asociados al badge son accesibles y coherentes.

Credencial verificada
La insignia se considera correcta cuando la assertion existe, la imagen se sirve como recurso real y el verificador puede resolver su contenido sin redirecciones problemáticas.
Requiere revisión
Debes revisar la publicación si la URL del badge no es pública, si el servidor devuelve text/html en lugar de image/png o si el recurso queda protegido por autenticación externa.

Problemas frecuentes

La imagen abre en el navegador, pero no valida

Esto suele ocurrir cuando el navegador accede con tu sesión, pero un verificador externo recibe una respuesta distinta, como una página intermedia o un recurso no público.

La miniatura no coincide con la imagen subida

Si la vista previa usa la imagen del badge_class en vez del fichero cargado en el formulario, la ayuda puede explicar claramente qué imagen se emplea en cada fase del proceso.

El badge existe, pero la URL no es verdaderamente pública

En entornos como Codespaces, marcar una ruta como pública dentro de FastAPI no siempre basta si el puerto o el dominio siguen protegidos a nivel externo.

Consejo práctico: antes de compartir una insignia fuera de tu entorno, comprueba que la URL responde directamente con Content-Type: image/png y no requiere sesión, token ni redirecciones a otra página.
